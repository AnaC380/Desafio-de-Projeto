## 📋 Sobre o Projeto

Este é um projeto de estudo que aplica conceitos fundamentais de programação, incluindo variáveis, operadores, estruturas de decisão e laços de repetição.

## 🎯 Funcionalidades

- Cadastro de heróis com nome e XP
- Classificação automática por níveis
- Validação de entrada de dados
- Processamento de múltiplos heróis em sequência

## 📊 Tabela de Classificação

| XP | Nível |
|---|---|
| Menos de 1.000 | Ferro |
| 1.001 - 2.000 | Bronze |
| 2.001 - 5.000 | Prata |
| 5.001 - 7.000 | Ouro |
| 7.001 - 8.000 | Platina |
| 8.001 - 9.000 | Ascendente |
| 9.001 - 10.000 | Imortal |
| 10.001 ou mais | Radiante |

## 🚀 Como Executar

1. Clone o repositório
```bash
git clone https://github.com/AnaC380/Desafio-de-Projeto.git
```

2. Abra o projeto no Visual Studio

3. Execute o programa (F5)

4. Insira o nome do herói e a quantidade de XP

## 💻 Tecnologias Utilizadas

- C#
- .NET Framework
- Visual Studio

## 📝 Exemplo de Uso

```
=== SISTEMA DE CLASSIFICAÇÃO DE HERÓIS ===

Digite o nome do herói: Thor
Digite a quantidade de XP do herói: 8500

O Herói de nome Thor está no nível de Ascendente

Deseja classificar outro herói? (S/N):
```

## 🎓 Conceitos Aplicados

- Declaração e manipulação de variáveis
- Operadores de comparação e lógicos
- Estruturas condicionais (if/else)
- Laços de repetição (do-while)
- Validação de entrada com TryParse
